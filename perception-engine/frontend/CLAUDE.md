# Manager PE Frontend Guidance

This package is the React/Vite frontend for Perception Engine management.

- Keep UI assumptions aligned with backend PE source/state APIs.
- Prefer TypeScript language server plus CSS/HTML support.
- Rebuild with `npm run build` after frontend changes.
- Update nearby docs and the repo `CLAUDE.md` when visible PE workflows or operational expectations change.

## Standing rules

The standing rules are in
`../../../RealityEngine_CI/docs/ENGINEERING_CONTRACT.md`, which is
authoritative. They are not listed or summarised here, so this file never
falls behind the contract. Read it before changing anything here.
